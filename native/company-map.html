The whole thing, in one picture

One causal chain, top to bottom: what is true on paper → the named objects of work → the machine that runs them → the products people buy — with governance checking every layer, and the desktop app as the face of it all. Every block is clickable. Each block answers one question: why does this exist?

Reading order: top to bottom, one arrow at a time. Deliberately not a sitemap — 7 primary blocks, at most 4 child links each; everything deeper lives one click down. The sidebar carries the full 115-page tree in the same order.

The same chain as one sentence each

BlockWhy it exists
TheorySo the rest is derived, not improvised — the laws come first.
The VocabularySo work has names, and names have rules — true on paper before any machine runs.
The PlatformSo the vocabulary executes — eleven blocks, each honest about what it is and how it’s built.
EngineeringSo the platform can actually be built — the material that cuts across all blocks.
ProductsSo someone can buy the result — Chief of Staff shipping, Senior Expert planned.
The AppSo all of it has one face — a chat, a decision stack, receipts.
GovernanceSo every layer above stays honest — the wrap that checks them all.
