Open / gaps — questions for the founder

  • All 5 pillars' Ring 1 Surface rows (Problem space / Need-outcome / Solution direction) are 'Awaiting founder fill' (T-G1-02..T-G1-16) — could founder voice shift any PRIMARY assignment once filled?
  • Sec.4.1 puts LLM calls inside Workflow Steps (Step = 'LLM call OR deterministic action... where work happens' — SoP runtime) and ADR-005 selects the host-LLM per workflow, yet B1's parse contract ('pre-declared output schema shown before LLM call') sits in Orchestration's translate step — which block issues B1's intent-parse LLM call?
  • Section 1.0 gives Compute no pillar-differentiated role — does B5 'keep it mine' imply local-compute data residency on the host machine, or is Compute a uniform substrate for all pillars?
  • B3b DO external effects: the section-1-0-runtime diagram labels the SoP-to-External-World edge 'context + effects', but B3's Connectedness routes external touches only via B4 — do non-comms tool effects bypass B4 or traverse it?
  • Inbound B4 responses 're-enter via B3 (next action)' — does re-entry traverse Orchestration as a fresh translate, or go straight into the running System of Process? Doc is silent.
  • B5 says 'operator can write standing prefs directly' — the write path (UI direct to System of Record vs routed through System of Process) is unspecified in the cited ranges.
