The machine side (what agents read)

  • manifest.json — one row per box on the map: id · level · parent · status · version · owner · acceptance. THE work queue.
  • BUILD-PROTOCOL.md — the loop any agent session runs, plus the mandatory page anatomy (map → work-order → diagram → tables → text).
The trick that makes this agent-buildable: every page carries its own work-order header (open any page — table right under the map). "Give the doc to Claude" = point a session at manifest.json; it finds what is unfinished, what done means, and where the page sits in the cascade. You never re-explain the project.
