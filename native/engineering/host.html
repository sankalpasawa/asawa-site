ADR-005 — per-workflow host-LLM selection (claude --bare vs codex exec)adr-decisionDecision: "Native engine MUST require WorkflowStep.host ∈ {claude, codex} whenever action='invoke_host_llm'". host='claude' invokes claude --bare — recursion-safe (no plugin sync, no CLAUDE.md auto-load, no hooks; skips keychain reads so unauthenticated for connector calls); default for steps that must execute in the founder's session via the effector split (ADR-004). host='codex' invokes codex exec — read-only sandbox; default for analysis, review, planning steps producing JSON/text without state change.
