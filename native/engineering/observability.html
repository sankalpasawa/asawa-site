ADR-013 — telemetry sink: fsync'd JSONL appendadr-decisionDecision: "Native engine MUST persist EngineEvent and DecisionProvenance as fsync'd JSONL append-only files; H-Sutra event bus MUST follow the same shape." Mechanics: one JSONL line per event/decision; UTF-8; no newline-in-field (sanitized at emit); fsync per append — never lose a row on crash; stderr beacon fallback when primary path is unwritable; dual fallback to /tmp (HS-4 chain); the pattern detector (ADR-010) reads the log directly — no in-memory cache, restart-safe. Alternatives rejected: in-memory ring buffer (fails restart-survival — codex P1.2 forced rejection) and SQLite/DB (adds dependency + schema migrations). Consequences: crash-safe; zero new runtime dependency; multi-process safe (POSIX append atomicity for short lines); disk I/O cost per event accepted at current rate; no indexed query — replay is sequential scan, aggregation is downstream tooling; OTel production transport (OS-10) is the next-tier deferral, JSONL stays primary.sutra/os/decisions/ADR-013-telemetry-sink-fsync-jsonl.md
