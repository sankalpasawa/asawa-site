Emission → persistence path (cited, drawn in full on eng/observability): every state transition across every surface emits exactly one typed EngineEvent; consequential decisions additionally emit one DecisionProvenance row; the AUDIT surface persists both as fsync’d append-only JSONL (ADR-013). Replay rebuilds any consequential decision from agent_identity + policy_id + policy_version + data_refs + outcome (§6.1). No audit_log_write_failed event type exists — HS-4 uses a stderr beacon, not an EngineEvent (canon gap, carried on observability).

How the four families compose — the whole-system reading

The per-part pages each answer “how does THIS part work.” Read together as a boundary, they answer a different question: every wire crossing Native’s edge passes through the same governed spine. Inbound (operator utterance via UI; verified external message via Connector) enters through ROUTE; the SoP/RUN surface drives the Step machine; any outbound effect (Connector send, peer A2A in v2+) passes the Authority + Tenancy gate before leaving; and every transition on every one of these interfaces emits an EngineEvent that the AUDIT surface persists. That is the cross-cutting invariant no single part page states in full: four interface families, one gate, one event bus, one durable sink. The mechanism-level proof of each clause lives on the page named in its row — this view is the index that makes the boundary legible as a whole.
