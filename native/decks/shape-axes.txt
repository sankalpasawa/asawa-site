4. HOW: HOW EACH AXIS IS READ AND APPLIED
-----------------------------------------
  Every SHAPE axis works the same way: someone reads the ask, writes one small reading, and the reading
  constrains the next axis. Nothing is carried over from the last run.

  Axis          Reads                      Who reads it            Writes                           Where it lives today (Core)
  ------------  -------------------------  ----------------------  -------------------------------  ---------------------------------------
  TYPE          the words of the ask       the turn classifier     one word: task | question |      every turn is classified before any
                                                                   direction                        work (the header line of each turn)
  CERTAINTY     how known the ground is    the agent, per turn     a Cynefin reading: clear |       a cynefin reading is written every turn
                                                                   complicated | complex | chaotic  (the turn's cynefin file)
  LENS          where the seams are,       the agent, per turn     the cut: which lens, the         a lens reading is written every turn;
                plus prior cuts of this                            children, how they wire; written  it reads prior decomposition history
                kind                                               onto each child's goal line       and writes the chosen pattern to the
                                                                                                    step's goal constraint (LENS P4)
  IMPACT        the goal's dimension       the owner, with the     one measure with a direction,    ruled 2026-09-25, not built; today the
                                           agent                   set before, read back at close   done line on the charter stands in
  control-flow  the children's dependence  the agent               parallel | sequence              the engine's steps, drawn by Adaptation
  depth         how much the ask deserves  the agent               a depth 1-5                      the depth line of each turn
  pace          how fast it must go        the owner               a cadence or "now"               the cadence on every engine

  The order is fixed: TYPE gates (a question is never cut like a task), CERTAINTY staggers (a probe is
  not cut at all, a do is cut at once), LENS cuts, IMPACT numbers the pieces, the finer three set how
  the pieces run. Then the plan is handed to RUN.

6. WHAT THE PAGE SAYS THESE AXES ARE NOT
----------------------------------------
  Which shape worked best over many runs    -> GROW (Codify writes the proven practice, SHAPE reads it)
  Whether the chosen shape may proceed      -> GOVERN (authority over the shaping transition)
  Pace that becomes motion over the loop    -> TIME (dynamics)
  The sorting test is the referee: only read-the-input-fresh stays in SHAPE.
