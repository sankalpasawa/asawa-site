The founder's direction this page is cut from (verbatim, 2026-10-16)

"I don't want to lock on the implementation, and that should be the genesis of creating the thought. The completeness of the thought starts with the theory that everything can be modeled out via axes and various axes when they come together. The idea is: how should we implement those axes so that multi-axis can be solved simultaneously? One of the examples, one of the ways of implementation, is the current way of what we have in the entire documentation, but there would be other ways."

"There's a section called Compass and Axis. You can just move it in one place. The axis, which is like the theory part of it. For each of the axes, each of the families of axes, I think we have six families of axes and some new families, like new axes which are not part of any of the families. We are thinking about: what each axis means; how each axis should be modeled out; what kind of things it should solve; how it works on axis and values for each of the axes; what families they belong to. We have a list of all axes and various parts. How do we ensure the science of the axis? How do we not have redundancies? What does axis mean? What does the new axis mean? When should an axis be retired? The entire science of how to think about an axis so that it's very elegant in a shorter form."

"Once we have enough theory and understanding of the axis, then we can go about implementing. How do we cut the work in such a way that it cuts along various axes to do it? This is one part of the theory. Another part is that all these works which are cut work towards one particular artifact. All the work which is to be done and which is cut along any kind of axis works towards artifacts. Artifact science is also there, wherein every work is contributing towards an artifact from each other. That is also part of this theory."

"Can we also ensure that all the work we do is just reorganization? No new work is created in the content. Any new work that has to be created, just put a label like 'work needs to be done' there, and we just use existing things which we have written and just cut and paste those things."

Dictation wrote "access" for "axis" throughout; the founder confirmed "axis not access" in the same session.
