Prose — what this page says

Identity: the consumer product IS the §1.0 UI block — one surface, two names. The frozen draft titles it “UI (Consumer Product)” and the doc spine reads “Needs → Consumer Product (this page) → Platform Product → Implementation” (master §1.0.1 so-ui). There is no separate consumer-product block anywhere in the locked schema.

The UI does not think. Per the locked first-layer schema, it carries gated intent down to the Host (Claude CLI — agent runtime + model in one) and results back up to the Human; the request runs on the Host (master §1.0).

Re-cut provenance. The MECE re-cut follows the founder-accepted DeepSeek review (2026-06-11): Standing surfaces (Daily Pulse · capability map · proactive surfacing · weekly retro) folded INTO Receive as its scheduled/proactive sub-case; Trust moments folded INTO Ask (confirm-back B.4, ask-before-acting F.1/F.5) and Receive (M5 approval card, F.2 reversibility, F.3 replay); Need-surfaces and Adaptation demoted to RENDER-ONLY annotations that must not leak into the engine as parts.

Authority + Tenancy renders on edges, never as a box. The §1.0 wrap surfaces here as gate glyphs on the edges where approval moments occur (ask-before-acting on intent-down; M5 approval card on results-up). Operator-visible states (error · empty · onboarding · notification) all land via Receive as M1–M6 deliveries.

Platform UI Kit — operator-facing governance surfaces (ADR-023)

Beyond replying to asks, the UI block is the render home for the Platform UI Kit: a Layer-A render library that exposes governance state to the operator (domains, charters, what is running, what awaits approval). Per ADR-023 this adds no new §1.0 block — the Kit’s components render inside this block’s Receive part as a new render-only area (Governance Surfaces), siblings of the M1-M6 modalities and Standing Surfaces. Components render read-only projections; they never execute (the existing render-only guard). An operator action (e.g. approve) submits an EXISTING utterance through Ask → GATE/EMERGE — never a direct component mutation.
