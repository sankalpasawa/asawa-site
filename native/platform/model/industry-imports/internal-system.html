Build sketch

  2. Define a subscription record: {member_engine_ref, resource, window_claim} — e.g. W-emi-reconcile claims core-banking window 02:00-04:00.
  3. Register the existing mechanisms (flock mint lock in placement_engine.py, dispatch freeze-at-bind at sutra-atom:310-318) as standards rows so the 'scattered' gap in Implementation-today closes.
