Every mechanism the 2026-08-07 industry research marked REUSE-AS-IS or ADAPT, converted into a build-ready candidate feature. One subpage per model part; every card has a stable anchor, a concrete Native landing site, and a build sketch — so when a card is picked up, the build path is already clear.

Epistemic status: candidates, not doctrine. These derive from external traditions (BPMN, Temporal, TPS/TWI, VSM, Scrum, ISO/ITIL, SRE/ICS, mission command, AI-agent frameworks). A card enters Native semantics only when the founder moves it past TODO. Review protocol: read card → rule (APPROVED / REJECTED / DEFERRED) → dated bullet lands in the card’s Review notes.
Status ladder: TODO → APPROVED / REJECTED / DEFERRED → DESIGNING → BUILDING → SHIPPED. All 120 cards are TODO as of 2026-08-07.
