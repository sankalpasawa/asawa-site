Long-term direction DRAFT

One person runs the entire office work through AI: an organisation of departments, each running its engines, each write an ask the person stamps. Deploying that to everyone is too broad as a product, so the first niche is a website for an existing organisation, its digital footprint, and the experience is built there and grown on top.

Broad goal to first niche to platform shape — grown on top of the website department.

"I'm trying to find a niche use case ... creating a website ... is a niche use case for that"the first product line
