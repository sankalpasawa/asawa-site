§1 — Definition

Native is the deployable Sutra plugin (sutra/marketplace/native/) that one founder + one LLM install with a single command to run a whole company's operating layer end-to-end. Implements the V2.4 Sutra Engine architecture (4 primitives + 6 laws + Skill Engine + 6 terminal-check predicates) on top of 10 capabilities — 5 fully covered, 4 partial, 1 deferred.
