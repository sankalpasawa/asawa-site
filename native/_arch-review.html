How a process runs

  1. The operator asks through the UI.
  2. It runs on the Host (Claude CLI) — the agent runtime + model in one.
  3. Inside the always-on Daemon: Orchestration translates the request and finds the relevant process to run.
  4. The process runs (this is the runtime): gathers context from System of Record + the External World, and writes its output back to System of Record.
  5. Every access passes Authority + Tenancy. The Host + daemon run on the Compute (host machine).
Top layer only · second level (context-build · verify · connectors) lives inside System of Process. Working artifact.
