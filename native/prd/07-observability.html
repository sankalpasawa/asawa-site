Accuracy is a per-workflow KPI, not a single number. Each task tier (T0-T3) + each pillar carries its own accuracy band. §4.5 Test-before-conclude is where the test runs; §7.1.A is where the aggregated results live.

§7.3 Operator satisfaction signals

  • Time-to-decision (operator decides on CoS output in <30s — CX bar gate)
  • Refusal-to-execute rate (operator says "don't do this, ask me first")
  • Autonomy-dial direction (does operator dial autonomy up or down per domain over time?)
  • Surface-switching frequency (operator should NOT switch surfaces mid-task per CX bar)

§7.4 Acceptance criteria (Observability v1)

  • 5-artifact audit trail emitted per turn (HS-4 fires on any missing channel).
  • Operator can request replay for any past turn within ≤30s for a single-day window.
  • Drift signals tracked weekly; breach surfaces to founder via Daily Pulse.

§7.5 Daily Pulse — operator's daily aggregate dashboard (Module per §1.4)

Daily Pulse is the visible artifact of §2.E S5 whole-system state. Auto-generated by holding/hooks/observability-synthesis.sh from session-end data. Operator reads once/day to see what CoS did + drift signals across the portfolio.

Hierarchy tag: Daily Pulse is a Module per §1.4 Product Hierarchy — composes cap-Telemetry + cap-Audit + cap-CrossPortfolio-Priority. Independent lifecycle. Per-Deployment BINDING (operator config: pulse cadence, channel, signal thresholds). Own RUNTIME STATE (daily-pulse archive per tenant). Reusable across future products on Native (designed for, not guaranteed v1).

§7.5.2 Operator commands

  • /asawa — CEO dashboard for portfolio overview
  • /status — current session status + drift signals
  • Daily Pulse delivered via holding/OBSERVABILITY-PULSE.md + optional email/Slack push per Charter

§7.5.3 Acceptance criteria (Daily Pulse v1)

  • Pulse auto-generates within 60s of session-end (no manual trigger needed).
  • Operator scans pulse + decides next actions in ≤2 minutes (CX bar gate per D.7).
  • Drift breach surfaced visually (boxed callout) — impossible to miss.
  • Cross-portfolio priorities ranked by Charter weight + recency + risk per §3 HOW decomposition.
